О сервисе VK Chat Exporter

Официальная авторизация и безопасность

Сервис использует исключительно официальный протокол VK OAuth 2.0 / VK ID. Приложение не собирает ваши логины и пароли, не использует сторонние библиотеки для парсинга и не сохраняет текст ваших сообщений в долговременную базу данных.

Ограничения VK API для сообщений

Методы messages.getConversations и messages.getHistory защищены правилами ВКонтакте. Для прямого доступа к личным сообщениям VK требует прохождения модерации в кабинете разработчика VK (dev.vk.com) или использования типа приложения «Standalone».

Формат выгрузки

[04.09.2026 21:14] Имя Собеседника:
Текст первого сообщения

[04.09.2026 21:15] Вы:
Ответное сообщение
[Вложение: фото]

Вложения помечаются читаемыми маркерами [Вложение: фото], [Вложение: видео], [Вложение: голосовое сообщение] без битых ссылок и тяжелых медиафайлов.

Вход по токену ВКонтакте

ВКонтакте запрещает обычным сайтам на dev.vk.com читать личные сообщения без сложной модерации. Авторизация по личному токену даёт полноценный доступ к вашим диалогам для скачивания в .TXT.

Вход по токену VK:

Если у вас уже есть токен доступа ВКонтакте (например, от мобильного клиента или VK Standalone), вставьте его в поле ниже. Сервис подключится к API и отобразит ваши диалоги.
